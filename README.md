# ai_agent

音声対話型のAIアシスタントエージェント。OpenAIのAPIとFAISSベクトル検索を組み合わせ、過去の会話ログを参照しながら文脈に沿った応答を生成する。

## 概要

ユーザーの音声入力を受け取り、過去の会話履歴をベクトル検索で取得したうえでLLMに渡すことで、連続性のある対話を実現する。会話ログはSQLiteに蓄積され、FAISSインデックスを通じて意味的に近い過去のやりとりを検索できる。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `main.py` | エントリーポイント（旧バージョン） |
| `main_kai.py` | エントリーポイント（改良版） |
| `llm.py` | LLM呼び出し・連続性判定・応答生成 |
| `DB.py` | SQLiteへの会話ログ保存・取得 |
| `vector.py` | FAISSを用いたベクトルインデックス管理・類似検索 |
| `voice.py` | 音声入出力（TTS / STT） |
| `input.py` | ユーザー入力受け付け |
| `bunkai.py` | 発話の分解・前処理 |
| `view.py` | ログ表示ユーティリティ |
| `ex.py` | 実験・検証用スクリプト |

## 主な技術スタック

- **LLM**: OpenAI API / Groq API
- **ベクトル検索**: FAISS
- **データベース**: SQLite
- **音声**: sounddevice / soundfile

## 開発状況

現在、`rewrite` ブランチにて以下のリファクタリングを進行中。

- **クラスベースへの移行**: 各モジュールをクラスとしてまとめ、責務の分離と再利用性の向上を図っている
- **MCP（Model Context Protocol）化**: ツール呼び出しの仕組みをMCPに準拠した形式へ移行し、外部ツールとの連携を標準化する
- **参照型アーキテクチャへのリライト**: NotebookLMのように、ドキュメントや過去ログを「参照ソース」として明示的に管理・引用できる構造へ再設計する
